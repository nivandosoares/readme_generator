# Gerador de README

Interface Next.js para gerar documentação com base nos arquivos de um repositório, com testes de integração das funções auxiliares.

**Arquivos principais**

- [package.json](<package.json>)
- [__tests__/lib/](<__tests__/lib/>)

## Desenvolvimento local

Com Node.js e npm instalados, execute na raiz:

```sh
npm ci
npm run dev
```
